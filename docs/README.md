# Notopo Prospect Intelligence

Notopo Prospect Intelligence is a Chrome extension-based prospect intelligence platform scaffold designed for future enrichment, analytics, and workflow automation.

## Project Structure

- extension: Manifest V3 Chrome extension with popup, background, and content scripts
- api: Backend server and placeholder routes/controllers
- dashboard: Frontend dashboard shell for future analytics views
- database: SQL schema starter for prospect-related data
- docs: Project documentation and planning notes

## Status

This repository currently contains the complete project structure with placeholder files and comments only. No business logic has been implemented yet.

- Implement extension features and UI interactions
- Build API endpoints and data services
