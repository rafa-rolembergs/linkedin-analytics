# Notopo Prospect Intelligence

Notopo Prospect Intelligence is a Chrome Extension scaffold built with Manifest V3 for prospect intelligence workflows. The project is intentionally structured as a clean starting point for future extension, API, dashboard, and database development.

## Project Structure

- extension: Chrome extension assets, including the Manifest V3 configuration, background script, content script, popup UI, and icons
- api: Backend server scaffold with routes and controllers
- dashboard: Frontend dashboard shell for analytics views and reporting
- database: SQL schema starter for prospect-related data
- docs: Project documentation and planning notes

## Current Status

This repository currently contains the complete requested project structure with placeholder files and comments only. No business logic has been implemented yet.
